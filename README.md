# Life Hub

Личное приложение «всё в одном»: дневник питания, дневник тренировок, календарь с задачами и обучение (расписание пар, план самообучения, учёт времени).

**Стек:** React 18 + TypeScript + Vite + three.js · Go 1.24+ (`net/http`, `database/sql`, `lib/pq`) · PostgreSQL 16 · Docker Compose

**Выложить в интернет бесплатно (GitHub → Render + Neon) — пошагово в [DEPLOY.md](DEPLOY.md).**

## Возможности

| Раздел | Что умеет |
|---|---|
| **Сегодня** | График продуктивности за 7/14/30 дней (балл 0–100 из задач, учёбы и тренировок) и сводка дня: пары с учётом чётности недели (идущая пара подсвечивается), задачи, питание, тренировка, время учёбы. Можно листать дни |
| **Календарь** | Месячная сетка с метками (задачи, тренировки, учёба, питание), панель выбранного дня, просроченные задачи, задачи без даты |
| **Учёба → Расписание** | Пары по дням недели, верхние/нижние недели, быстрый выбор времени пары, дата начала семестра → номер недели |
| **Учёба → План** | Темы/курсы: цель в часах, дедлайн, статус, прогресс-бар по записанному времени |
| **Учёба → Время** | Запись занятий (с темой или без), статистика и график за 14/30/90 дней |
| **Мозг** | Игровая 3D-визуализация развития (three.js, свечение, вращение мышью/пальцем): нейросеть внутри голографического мозга, зоны растут от учёбы, навыков, книг, задач и тренировок; уровни, опыт, достижения, анимация роста и «нового уровня». Мини-версия — на главной |
| **Учёба → Книги** | Книги: хочу прочитать / читаю (страницы, прогресс) / прочитано (дата, оценка, заметки), область знаний |
| **Питание** | Записи свободным текстом со временем приёма пищи (по умолчанию — текущее), экспорт в Excel за выбранный период |
| **Тренировки** | Простой журнал: тип, длительность, заметка; статистика за 7/30 дней |

Есть тёмная тема (по системной настройке) и мобильная вёрстка с нижней навигацией.

## Быстрый запуск (Docker)

Нужен [Docker Desktop](https://www.docker.com/products/docker-desktop/).

```powershell
cd C:\Users\dguse\source\repos\life-hub
docker compose up -d --build
```

Открыть: http://localhost:8080

Данные хранятся в volume `pgdata` и переживают перезапуск. Остановить: `docker compose down` (с `-v` — удалить и данные).

## Режим разработки

Нужны Go 1.22+, Node.js 20+ и Docker (только для базы).

```powershell
# 1. База
docker compose up -d db

# 2. Бэкенд (http://localhost:8080). Миграции применяются автоматически при старте
cd backend
go run ./cmd/server

# 3. Фронтенд с hot reload (http://localhost:5173), /api проксируется на :8080
cd frontend
npm install
npm run dev
```

Переменные окружения бэкенда:

| Переменная | По умолчанию |
|---|---|
| `DATABASE_URL` | `postgres://lifehub:lifehub@localhost:5432/lifehub?sslmode=disable` |
| `ADDR` | `:8080` |
| `STATIC_DIR` | пусто (если задан — бэкенд раздаёт собранный фронтенд) |
| `PORT` | если задан — слушать `:PORT` (так делают Render и подобные хостинги) |
| `TRUST_PROXY` | `1` — за обратным прокси с HTTPS: доверять `X-Forwarded-*` (secure-cookie, IP для лимита попыток входа) |
| `TZ` | часовой пояс сервера и сессий БД, например `Europe/Moscow` |

## Аккаунты и безопасность

- У каждого пользователя свои данные во всех разделах. Во всех таблицах есть `user_id`; сервер выполняет каждый запрос в транзакции с `app.user_id` текущего пользователя, а SQL-запросы фильтруют по `app_uid()` — без входа запросы не видят ничего.
- Регистрация — только по одноразовой ссылке-приглашению (`/join/<код>`, 14 дней), которую создаёт администратор в «Профиле». Первый зарегистрированный пользователь становится администратором и получает данные, внесённые до появления аккаунтов.
- Пароли — PBKDF2-SHA256 (310 000 итераций, соль), сессии — случайный токен в `HttpOnly`/`SameSite=Lax` cookie (в базе только его SHA-256), 90 дней со скользящим продлением; смена пароля завершает остальные сессии.
- Лимит попыток входа/регистрации (10 за 10 минут с одного IP), проверка `Origin` для изменяющих запросов, заголовки `nosniff`/`X-Frame-Options`.
- Интеграционный тест изоляции данных двух пользователей: `TEST_DATABASE_URL=postgres://…/test_db?sslmode=disable go test ./...` (**очищает** указанную базу).

## API

Все даты — `YYYY-MM-DD`, время — `HH:MM`. Ошибки: `{"error": "..."}`.

| Метод | Путь | Описание |
|---|---|---|
| GET | `/api/auth/status` · `/api/auth/me` | Есть ли пользователи · текущий пользователь |
| POST | `/api/auth/register` · `/api/auth/login` · `/api/auth/logout` | Регистрация (`invite`, `username`, `name`, `password`), вход, выход |
| PUT | `/api/auth/password` | Смена пароля (`current`, `new`) |
| GET/POST · DELETE | `/api/invites` · `/api/invites/{code}` | Приглашения (только админ); `GET /api/invites/{code}` — проверка ссылки |
| GET | `/api/ping` | Проверка живости без обращения к БД |
| GET | `/api/day?date=` | Всё по дню: пары (с учётом чётности), задачи, питание, тренировки, минуты учёбы |
| GET | `/api/calendar?month=YYYY-MM` | Счётчики по дням месяца |
| GET | `/api/productivity?from=&to=` | Балл продуктивности по дням с разбивкой по частям |
| GET/POST | `/api/food?from=&to=` | Дневник питания |
| PUT/DELETE | `/api/food/{id}` | |
| GET | `/api/food/export?from=&to=` | Скачать дневник питания в Excel (.xlsx); без параметров — всё время |
| GET/POST | `/api/workouts?from=&to=` | Тренировки; `GET /api/workouts/kinds` — использованные типы |
| PUT/DELETE | `/api/workouts/{id}` | |
| GET | `/api/tasks?from=&to=` · `?undated=true` · `?overdue=true` | Задачи |
| POST · PUT/DELETE | `/api/tasks` · `/api/tasks/{id}` | |
| PATCH | `/api/tasks/{id}/toggle` | Выполнено / вернуть |
| GET/POST · PUT/DELETE | `/api/classes` · `/api/classes/{id}` | Расписание пар (`parity`: `all`/`odd`/`even`) |
| GET/POST · PUT/DELETE | `/api/study/topics` · `/api/study/topics/{id}` | План самообучения (с `spent_minutes`) |
| GET/POST · DELETE | `/api/study/sessions` · `/api/study/sessions/{id}` | Занятия |
| GET | `/api/study/stats?from=&to=` | Минуты по дням (включая нули) |
| GET/POST · PUT/DELETE | `/api/books` · `/api/books/{id}` | Книги (`status`: want/reading/done, `area`) |
| GET | `/api/brain` | Опыт и уровни по зонам мозга, достижения, статистика |

| GET | `/api/health` | Проверка состояния |

Пример:

```bash
curl -X POST localhost:8080/api/food -H "Content-Type: application/json" \
  -d '{"date":"2026-10-10","time":"08:30","content":"Овсянка, банан, кофе"}'
```

## Верхняя и нижняя неделя

Укажи дату начала семестра во вкладке «Расписание». Неделя, в которую попадает эта дата, — 1-я, верхняя (нечётная); дальше недели чередуются по понедельникам. Пары с пометкой «Верхняя»/«Нижняя» показываются только в свои недели; если дата не указана — показываются все пары дня.

Расписание группы БИВТ-24-АЭ-3 на осенний семестр 2026 загружается миграцией `003_schedule_bivt_24_ae_3.sql`.

## Балл продуктивности

Каждый день получает балл от 0 до 100:

| Часть | Максимум | Как считается |
|---|---|---|
| Задачи | 40 | доля выполненных задач, запланированных на этот день |
| Учёба | 40 | минуты учёбы относительно дневной цели (по умолчанию 2 ч, меняется под графиком) |
| Тренировка | 20 | была ли хотя бы одна тренировка |

Если на день не было задач, эта часть не учитывается, а учёба и тренировка пересчитываются к 100 — день без задач не штрафуется. Формула — в `backend/internal/api/productivity.go`, тесты — в `productivity_test.go`.

## Мозг: опыт и уровни

| Источник | Опыт | Зона |
|---|---|---|
| 1 минута учёбы | 1 XP | по области темы (без темы — логика) |
| Тема «Готово» — новый навык | 150 XP | по области темы |
| Прочитанная книга | 100 + страницы/2 (без страниц — 150) | по области книги |
| Книга в процессе | прочитанные страницы/2 | по области книги |
| Выполненная задача | 10 XP | лобная доля |
| Тренировка | 30 + минуты/2 | мозжечок |

Области знаний → зоны: логика и технологии — теменная доля, языки и гуманитарное — височная, творчество — затылочная, саморазвитие — лобная.
Общий уровень: уровень *L* начинается с 50·(L−1)² XP; уровень зоны — с 30·(L−1)² XP. Чем больше опыта в зоне, тем больше в ней горит нейронов (рост замедляется, как в играх).
Расчёт — `backend/internal/api/brain.go`; 3D-сцена — `frontend/src/components/brain3d/` (процедурная модель коры, мозжечка и ствола, нейроны, связи, импульсы, bloom), если WebGL недоступен — 2D-версия из `frontend/src/components/brain/`. Что пользователь видел в прошлый раз, хранится в `localStorage`, поэтому рост и «новый уровень» анимируются с прошлого визита.
