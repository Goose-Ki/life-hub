# Как выложить Life Hub в интернет бесплатно

Схема: **код на GitHub → приложение на Render → база данных в Neon**. Все три сервиса бесплатные и не требуют банковской карты.
После настройки каждый `git push` в GitHub автоматически обновляет сайт.

| Что | Где | Бесплатно |
|---|---|---|
| Код | GitHub | да |
| Приложение (Go + React в одном контейнере) | [Render](https://render.com), тариф Free | 750 ч/мес, засыпает после 15 мин без запросов |
| База PostgreSQL | [Neon](https://neon.com), тариф Free | 1 ГБ, бессрочно, засыпает после 5 мин простоя |

Адрес будет вида `https://life-hub-xxxx.onrender.com`.

---

## 1. Загрузить код на GitHub

1. На [github.com/new](https://github.com/new) создай репозиторий `life-hub` (можно **Private**), без README.
2. В PowerShell:

```powershell
cd C:\Users\dguse\source\repos\life-hub
git init
git add .
git commit -m "Life Hub"
git branch -M main
git remote add origin https://github.com/Goose-Ki/life-hub.git
git push -u origin main
```

> `node_modules`, `dist` и прочее лишнее в репозиторий не попадёт — это прописано в `.gitignore`.

## 2. Создать базу в Neon

1. Зарегистрируйся на [neon.com](https://neon.com) через GitHub.
2. **Create project**: имя `life-hub`, Postgres 16, регион **AWS Europe Central 1 (Frankfurt)** — ближе всего к Москве.
3. На странице проекта нажми **Connect**. **Выключи «Connection pooling»** (нужна прямая строка, без `-pooler` в адресе) и скопируй строку вида
   `postgresql://neondb_owner:…@ep-…eu-central-1.aws.neon.tech/neondb?sslmode=require`

## 3. Развернуть на Render

1. Зарегистрируйся на [render.com](https://render.com) через GitHub.
2. **New → Blueprint** → выбери репозиторий `life-hub` (если он приватный — разреши Render доступ к нему).
3. Render прочитает `render.yaml` и попросит значение **DATABASE_URL** — вставь строку из Neon.
4. **Apply**. Первая сборка занимает 5–10 минут (собираются фронтенд и бэкенд). Статус **Live** — готово.
5. Открой адрес сервиса (вверху страницы, `https://life-hub-….onrender.com`).

## 4. Первый вход и приглашения

1. При первом открытии появится «Создай аккаунт администратора» — это ты. Твоё расписание пар (БИВТ-24-АЭ-3) уже будет в аккаунте.
2. **Профиль** (аватар внизу меню, на телефоне — кружок справа вверху) → **Создать ссылку-приглашение** → **Отправить** родным.
3. Каждая ссылка одноразовая и действует 14 дней. По ней человек создаёт свой логин и пароль — у него будут свои отдельные дневники, задачи, расписание и мозг.

На телефоне сайт можно «установить» как приложение: iPhone — «Поделиться → На экран „Домой“», Android — меню ⋮ → «Установить приложение».

## Необязательно

### Чтобы сайт не «засыпал» днём

На бесплатном Render после 15 минут без запросов сервис засыпает, и первое открытие ждёт около минуты.
В репозитории уже есть GitHub Action, который «будит» сайт каждые 10 минут с 07:00 до 24:00 по Москве (это укладывается в 750 бесплатных часов):

GitHub → репозиторий → **Settings → Secrets and variables → Actions → Variables → New repository variable**:
`APP_URL` = `https://life-hub-….onrender.com` (без `/` в конце).

Проверка ходит на `/api/ping` и не будит базу, поэтому не тратит лимит Neon.
GitHub отключает расписание, если в репозитории 60 дней не было коммитов, — тогда просто включи workflow снова во вкладке **Actions**.

### Перенести данные, уже внесённые локально

Делается **до первого входа на сайт** (пока база в Neon пустая). Docker Desktop должен быть запущен.

```powershell
cd C:\Users\dguse\source\repos\life-hub
docker compose up -d db
docker compose exec -T db pg_dump -U lifehub -d lifehub --no-owner --no-privileges | Out-File -Encoding utf8 backup.sql
Get-Content backup.sql | docker run --rm -i postgres:16-alpine psql "СТРОКА_ИЗ_NEON"
```

Потом открой сайт и зарегистрируйся — если локально аккаунтов ещё не было, все данные станут твоими.
Если локально ты уже создал аккаунт, просто войди тем же логином и паролем.

### Обновления

Любые изменения: `git add . ; git commit -m "…" ; git push` — Render пересоберёт и перезапустит сайт сам (2–5 минут). Данные в Neon при этом не трогаются, новые миграции применяются автоматически.

### Если что-то пошло не так

- **Render → сервис → Logs** — там видно ошибки запуска (например, неверная строка `DATABASE_URL`).
- `database unreachable` — проверь, что строка из Neon скопирована целиком и в ней нет `-pooler`.
- Забыл пароль администратора — пароли хранятся только в виде хэша; проще всего попросить меня добавить сброс пароля или создать новую ссылку-приглашение и новый аккаунт.
